# 📁 FINAL MapMyCivic Backend Structure

```text
mapmycivic-backend/
│
├── app/
│
│   ├── main.py
│   # FastAPI entry point
│   # Starts server and registers all routers
│
│
│   ├── core/
│   │   ├── config.py
│   │   # Loads environment variables
│   │   # Defines:
│   │   # DATABASE_URL
│   │   # SECRET_KEY
│   │   # UPLOAD_DIR
│   │   # MODEL_PATH
│   │
│   │   ├── database.py
│   │   # Creates database engine
│   │   # Provides DB session dependency
│   │
│   │   ├── security.py
│   │   # Password hashing (bcrypt)
│   │   # JWT token creation and validation
│   │
│   │   └── logging.py
│   │   # App logging setup
│
│
│   ├── models/
│   │   ├── user.py
│   │   # Stores users
│   │   # id, name, email, password_hash, role, created_at
│   │
│   │   ├── report.py
│   │   # Stores civic issues
│   │   # id
│   │   # title
│   │   # description
│   │   # image_url
│   │   # resolved_image_url
│   │   # latitude
│   │   # longitude
│   │   # issue_type (ML predicted)
│   │   # status (pending, in_progress, resolved)
│   │   # created_at
│   │   # resolved_at
│   │   # user_id
│   │
│   │   ├── notice.py
│   │   # Authority notices
│   │   # id
│   │   # title
│   │   # description
│   │   # image_url
│   │   # start_date
│   │   # end_date
│   │   # created_at
│   │   # created_by
│   │
│   │   └── __init__.py
│
│
│   ├── schemas/
│   │   ├── user_schema.py
│   │   # UserCreate, UserLogin, UserResponse
│   │
│   │   ├── report_schema.py
│   │   # ReportCreate
│   │   # ReportResponse
│   │   # ReportResolve
│   │
│   │   ├── notice_schema.py
│   │   # NoticeCreate
│   │   # NoticeResponse
│   │
│   │   └── __init__.py
│
│
│   ├── api/
│   │   ├── router.py
│   │   # Combines all route modules
│   │
│   │   ├── deps.py
│   │   # DB session dependency
│   │   # Authenticated user dependency
│   │
│   │   └── routes/
│   │       │
│   │       ├── auth.py
│   │       # POST /auth/register
│   │       # POST /auth/login
│   │       │
│   │       ├── users.py
│   │       # GET /users/me
│   │       # Admin user management
│   │       │
│   │       ├── reports.py
│   │       # POST /reports/create
│   │       # GET /reports/all
│   │       # GET /reports/{id}
│   │       # POST /reports/resolve/{id}
│   │       # PATCH /reports/status/{id}
│   │       │
│   │       ├── notices.py
│   │       # POST /notices/create (authority only)
│   │       # GET /notices/active (mobile app)
│   │       # GET /notices/all (admin)
│   │       │
│   │       └── health.py
│   │       # GET /health
│
│
│   ├── services/

│   │   # User creation and login logic
│   │
│   │   ├── report_service.py
│   │   # Create report

│   │   # Save resolved image
│   │
│   │   ├── notice_service.py
│   │   # Create notices
│   │   # Fetch active notices
│   │
│   │   ├── upload_service.py
│   │   # Saves uploaded images
│   │   # Handles:
│   │   # reports/

│
│

│   │   ├── preprocessing.py
│   │   # Image preprocessing
│   │
│   │   └── models/

│   │       # Trained ML model file
│
│
│   ├── utils/
│   │   ├── file_validator.py
│   │   # Validates file type and size
│   │
│   │   ├── image_validator.py
│   │   # Ensures valid image format
│   │
│   │   ├── geo_utils.py
│   │   # Optional geo helper functions
│   │
│   │   └── helpers.py
│
│
│   ├── constants/

│   │   └── issue_types.py

│
├── alembic/

│
├── tests/

│
├── requirements.txt

    # Optional simple startup script
```
